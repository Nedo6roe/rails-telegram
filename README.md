# Рельсы и дороги для Telegram

Папка содержит всё: сервер (`server.js`), игровую логику (`public/game.js`), Mini App (`public/index.html`) и бота (встроен в сервер). Зависимостей нет, нужен только Node.js 18+.

## Проверка на компьютере (без Telegram)
1. `node server.js`
2. Откройте в двух вкладках `http://localhost:3000/?dev=Аня` и `http://localhost:3000/?dev=Борис`.
3. В первой создайте игру, во второй войдите по коду.

## Запуск в Telegram
1. В Telegram откройте @BotFather, отправьте `/newbot`, получите токен.
2. Выложите папку на любой хостинг с Node.js и HTTPS (например Render.com: New Web Service, Start Command `node server.js`).
3. Задайте переменные окружения:
   - `BOT_TOKEN` — токен от BotFather
   - `BASE_URL` — адрес вашего сервиса, например `https://rails.onrender.com`
4. Откройте своего бота и отправьте `/start`: придёт кнопка «Играть». Кнопка «Играть» также появится в меню бота.

## Как играть
Создатель нажимает «Создать игру», затем «Пригласить друзей»: друзьям уходит ссылка на бота с кодом комнаты. Когда все зашли, создатель нажимает «Начать игру». Раунд идёт, пока все не подтвердят ходы.

## Что важно знать
- Комнаты хранятся в памяти сервера: при перезапуске сервера текущие партии пропадут.
- Бесплатные тарифы часто «засыпают» без активности, первый запуск может занять до минуты.
- Допустимость каждого хода проверяет приложение игрока, сервер проверяет формат поля и считает итоговые очки. Для игры с друзьями этого достаточно.
